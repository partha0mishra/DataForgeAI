# Pipeline Automation Accelerator Dependencies
#
# ⚠️ IMPORTANT: DEPENDENCY CONFLICT WARNING ⚠️
#
# This accelerator has TWO deployment modes with INCOMPATIBLE dependencies:
#
# 1. AIRFLOW MODE: Uses Apache Airflow 2.7.3 (requires Pydantic v1, SQLAlchemy 1.4.x)
#    - Install with: pip install -r requirements-airflow.txt
#    - Deploy in ISOLATED environment (separate Docker container)
#    - Cannot use with dataforge-common or dataforge-connectors
#
# 2. API-ONLY MODE: Uses FastAPI only (requires Pydantic v2, SQLAlchemy 2.0+)
#    - Install with: pip install -r requirements-api.txt
#    - Compatible with dataforge shared libraries
#    - No Airflow orchestration features
#
# See examples/usage.md for detailed deployment instructions
#
# DO NOT install all dependencies together - they will conflict!

# For specific requirements, see:
# - requirements-airflow.txt (Airflow orchestration environment)
# - requirements-api.txt (API-only environment)
