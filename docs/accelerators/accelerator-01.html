Quick Start

Docker Deployment

# Build the Docker image docker build -t accelerator-1 accelerators/01-*/ # Run the container docker run -d -p 8001:8001 accelerator-1 # Verify health curl http://localhost:8001/health

Local Development

# Navigate to accelerator directory cd accelerators/01-*/ # Install dependencies pip install -r requirements.txt # Run the application uvicorn src.main:app --host 0.0.0.0 --port 8001 --reload

Technology Stack

Framework: FastAPI 0.109.0 - High-performance async API framework

ORM: SQLAlchemy 2.0.25 - Database abstraction layer

Validation: Pydantic 2.5.3 - Data validation and serialization

Server: Uvicorn 0.27.0 - ASGI server for production

API Documentation
